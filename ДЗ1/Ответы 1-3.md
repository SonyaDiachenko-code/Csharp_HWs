# Ответы на задачи 1–3

## Задача 1

**а)** После выполнения сериализации в JSON будут включены только общедоступные свойства:

```json
{
  "PlayerName": "Max",
  "Points": 250
}
```

Свойство PlayerName и Points доступны сериализатору, поэтому их значения сохраняются. Поле accessKey не отображается, так как оно закрыто модификатором private. Поле IsActive также пропускается, поскольку по умолчанию System.Text.Json обрабатывает свойства, а не поля.

**б)** Для сохранения значения accessKey можно заменить закрытое поле свойством с публичным геттером и приватным сеттером:

```csharp
public int AccessKey { get; private set; } = 73;
```

Благодаря этому сериализатор сможет прочитать значение свойства, но изменить его из внешнего кода не получится.

**в)** Свойство IsActive не записывается в JSON, потому что оно объявлено как поле. Есть два варианта решения.

Первый — использовать свойство:

```csharp
public bool IsActive { get; set; }
```

Второй — добавить атрибут JsonInclude к полю:

```csharp
[JsonInclude]
public bool IsActive;
```

## Задача 2

**а)** Пример класса для хранения информации об игре:

```csharp
public class Project
{
    public string Name { get; set; }
    public int ReleaseYear { get; set; }
    public double UserRating { get; set; }
    public string[] Categories { get; set; }
    public bool SupportsOnline { get; set; }
}
```

**б)** При десериализации может возникнуть проблема с несовпадением регистра символов в названиях JSON-ключей и свойств класса. Для устранения этой проблемы можно включить соответствующую настройку:

```csharp
var settings = new JsonSerializerOptions
{
    PropertyNameCaseInsensitive = true
};

Project project = JsonSerializer.Deserialize<Project>(json, settings);
```

Теперь названия свойств будут сопоставляться независимо от того, используются в них заглавные или строчные буквы.

**в)** JSON-массив может содержать элементы разных типов, поэтому сам по себе такой массив является корректным. Но преобразовать его напрямую в массив, рассчитанный только на один тип данных, нельзя.

Для работы с такими данными подойдут следующие варианты:

```csharp
JsonElement data = JsonSerializer.Deserialize<JsonElement>(json);

object[] values = JsonSerializer.Deserialize<object[]>(json);
```

Первый вариант позволяет анализировать элементы JSON, а второй — получить массив объектов.

## Задача 3

1. **File.ReadAllText** — применяется для чтения небольших файлов, когда нет необходимости загружать данные частями.

2. **File.WriteAllText** — используется для сохранения информации с полной заменой предыдущего содержимого файла. Подходит для обычного автосохранения.

3. **FileStream с FileMode.Append** — позволяет записывать новые данные в конец большого файла. При этом не требуется загружать весь файл в память.

4. **File.Exists и File.ReadAllText** — сначала программа проверяет, существует ли нужный файл, а затем считывает его содержимое. Оба метода относятся к классу File.

5. **FileStream с FileMode.Open, Seek и Write** — используется, когда требуется изменить данные в конкретном месте файла. Метод Seek устанавливает позицию записи, после чего Write перезаписывает необходимые 10 байт, оставляя остальные данные без изменений.
